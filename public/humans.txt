/* THE PROTOCOL */

  Magpie is a permissionless Solana lending protocol. Users deposit
  approved memecoins or tokenized stocks as collateral and receive
  SOL co-signed by the protocol in seconds.

  Custodial-by-export — users can /export their private key at any
  time and self-custody. Every flow is on-chain verifiable via
  solscan.io or magpie.capital/stats.

  Loan terms: 2 / 3 / 7 days. LTVs: 20% / 25% / 30%. Sub-1% lifetime
  liquidation rate by design (short terms + low LTV + token-health
  watcher). Live count at magpie.capital/stats.


/* THE STACK */

  Smart contracts: Anchor (Solana mainnet)
  Site: Next.js 16 + Tailwind 4 on Vercel
  Bot: grammY framework + Node.js + PostgreSQL on Railway
  AI agent (Pip): Anthropic Claude Sonnet 4 / Haiku 4.5
  Indexing: on-chain events → Postgres, real-time
  Monitoring: Helius webhooks
